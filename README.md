# PulseHub — сотрудники и доступ

Небольшая панель для управления сотрудниками и их доступом к внутренним разделам компании. Проект написан для практики Spring Security и разграничения прав.

## Возможности

- вход по логину и паролю;
- создание и блокировка учётных записей;
- собственные роли с набором разрешений;
- защита методов через `@PreAuthorize`;
- запись изменений в журнал;
- интерфейс на Thymeleaf;
- локальная база H2.

## Доступ для демонстрации

```text
Логин: hubadmin
Пароль: hub2026
```

При первом запуске появляются роли `NEXUS`, `TEAM_LEAD` и `VIEWER`.

## Технологии

Java 17, Spring Boot 4, Spring MVC, Spring Security, Spring Data JPA, Thymeleaf, H2, Maven, JUnit и Mockito.

## Запуск

```bash
mvn spring-boot:run
```

Открыть в браузере: <http://localhost:8080>

Тесты запускаются командой:

```bash
mvn test
```

## Как устроено

- `domain` — сущности пользователя, роли и события;
- `repository` — интерфейсы работы с БД;
- `service` — правила приложения;
- `web` — контроллеры и формы;
- `config` — безопасность и начальные данные.

В проекте использованы MVC, Repository, Strategy и внедрение зависимостей. Слои разделены по ответственности, а контроллеры работают через интерфейсы сервисов.

Пароли сохраняются в виде BCrypt-хэшей. CSRF включён. Файл базы и сборка исключены из Git.
